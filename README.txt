INDONESIA UTILITY TOOLS — V1
================================
Static website siap di-deploy ke Cloudflare Pages.

Isi V1:
- Homepage responsive
- 5 kategori
- Search tools
- 10 tools aktif:
  1. Kalkulator Gaji
  2. Kalkulator Lembur
  3. Kalkulator THR
  4. Kalkulator Pesangon
  5. Kalkulator Bruto/Tara/Netto
  6. KG <-> MT
  7. Kalkulator BBM
  8. Kalkulator Volume
  9. Kalkulator Persentase
  10. Kalkulator Umur
- JPG -> PDF placeholder halaman (akan ditambahkan engine berikutnya)
- Privacy, Disclaimer, About, Contact
- Tanpa framework dan tanpa database; tools kalkulator berjalan di browser.

CATATAN SEBELUM PUBLISH:
1. Buka contact.html dan ganti email placeholder.
2. Review Privacy Policy dan Disclaimer sesuai kondisi website.
3. Jangan pasang kode AdSense sebelum situs benar-benar siap dan memenuhi kebijakan.
4. Setelah deploy, tambahkan domain sendiri jika sudah tersedia.


V1.1 additions: JPG->PDF, Excel->PDF, Word->PDF, PDF->Excel, PDF->Word. Document conversions use browser-side CDN libraries. PDF scan/OCR is not included yet.
